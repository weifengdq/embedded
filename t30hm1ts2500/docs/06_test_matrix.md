### 7.6 关键结论
9. **TC14 能用但有前提**：必须**总线静默**（停 BEACON、所有节点停发）+ **手动写 TD_CTRL**
   （封装的 `s2500 td ref/meas` 在 DLYM_DONE 就提前返回，距离阶段被掐断），见
   [`docs/results/2026-11-20_features.md`](results/2026-11-20_features.md) §2。
10. **TC6 设备时间可用、发送时间戳只落 TTSCC**：TSC 位域疑与手册/本仓库文档不一致，确认前只读 TTSCC。
11. **静默类实验（TD/HDD）有副作用**：之后 `s2500 info` 可能出现 `SYNC=0 / id=255`，
   需板端 `reboot` 恢复；实验前先记录 info，结束后必须复读。


1. **CSMA 与 PLCA 混跑是吞吐/抖动头号杀手**：TC387 碰撞 9278 → 5，TCP 稳定 8.80。
   各平台固件默认值已改为 follower `plca_en=1`（STM32H723 id1 / HPM id2 / S32K id3 / TC387 id4 / RK3506 id5）。
2. **SPI 提频收益有限，事务开销才是瓶颈**：RK3506 15 MHz + 批量突发已 8.70，升 25 MHz 只多 1%。
3. **S2500 的 MAC 硬件计数器不可信**（灌 5200 帧只报 53），判断吞吐用 netdev / iperf。
4. **lwiperf 不支持 iperf2 的 `-R`**：测上行必须板端作客户端、主机作服务端。
5. **`s2500 selftest` 的环回结果只能参考**（部分板 FAIL 但真实收发正常）。
6. **PLCA 场景以 PST 判断链路**，`link` 可能显示 DOWN。
7. **STM32H723 接替损坏的 F407 后已全部通过**：TCP 9.07/8.87、bench 9.71（826 fps）、ping 0.56 ms、协调者 ID=0 双向 20/20。F407 板子已物理损坏停用，数据仅作历史。
8. **S32K312 的 LPSPI0 已打通并设为默认**：TCP 6.26/7.75、ping 0.82 ms、SPI 层 13.27 Mbit/s；根因是 FIFO 2 字深 + TXWATER=3（写被静默丢弃）与接收路径逐位 CRC32。软件 SPI 保留回退。
9. **S2500 自发复位可被看门狗自愈**：2 s 周期检查 PLCA_CTL1/IDVER，检出后自动重初始化；HPM/H723/TC387 的 ping 中断分别为 1.44/0.83/0.40 s，正常 60 s 0 误判。

## 8. 怎么填这张表

### 8.1 流程

```
① 单板、不接总线 → 填 1.1–1.4、5.7、5.8（SPI / 自检 / 环回）
② 接入总线让主机当协调者 → 填 1.5、1.6、3.1、3.2、4.1
③ 多板同时在线 → 填 3.3、3.7、3.8、3.9
④ 故障注入 → 填 3.4、3.5、3.6、4.4、4.5
⑤ 性能 → 填 2.1–2.6、4.7
⑥ TC10 / TC6 / TC14 → 填 3.x、5.x（需要额外接线/工具）
```

### 8.2 判据（什么算"通过"）

| 类别 | 通过判据 |
| --- | --- |
| 基础连通 | IDVER=0x00000011；MAC 合法；ping 1000 次 0% 丢包 |
| 吞吐 | 硬件 SPI ≥ 5 Mbit/s；软件 SPI 只要求"与 SPI 时钟匹配" |
| PLCA | PST=1 且 PLCADIAG=0；并发 ping 0% 丢包 |
| 诊断 | 正常链路 SQI=7/7；HDD=0（端接正确时） |
| 故障注入 | 注入后对应诊断位置 1，恢复后能清 0 |
| TC10/TC6/TC14 | 数值单调/与实测线长一致/1 Hz PPS 输出 |

### 8.3 记录要求

* 每轮测试把原始输出贴到 `docs/results/YYYY-MM-DD_<platform>.md`。
* 表里的 ✅ 必须能指向一条实测记录，否则用 ⬜。
* 性能数字必须注明：工具（iperf2/bench）、时长、包长、PLCA 开关状态。

## 9. 常见错误与排查

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 同一项两次测出来差很多 | 多板并发互相干扰 | 吞吐测量必须串行（`flock`） |
| ping 0% 丢包但 iperf 波动大 | 主机侧其他进程占用；lwIP 窗口小 | 关掉无关进程；增大 TCP_WND |
| `iperf3` 完全连不上 | 板端是 lwiperf，只支持 iperf2 | 用 `iperf`（v2） |
| SQI 一直 0 | 总线空闲时正常；没跑流量 | 边 ping 边测 |
| HDD 报错但通信正常 | 端接过多（余量不足） | 修端接后复测 |
| TC14 测出来距离明显不对 | 测量期间总线不静默 | 关掉 PLCA 协调者 BEACON |
| TC10 睡下去叫不醒 | 唤醒音/WAKE 没接 | 见例 14 |
| 长时间压测后 shell 无响应 | UART RX 溢出未恢复（已知问题 R5） | 重上电；建议加错误恢复 |
