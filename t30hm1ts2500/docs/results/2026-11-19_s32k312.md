# 实测记录 — 2026-11-19 S32K312 + T30HM1TS2500

> **后续更新（2026-11-20）**：LPSPI0 已打通并设为默认，TCP 6.26/7.45–7.75 Mbit/s；
> 本文的软件 SPI 数据（1.17/1.40）仅作历史对比，见 [`2026-11-20_s32k312.md`](2026-11-20_s32k312.md)。

环境：Ubuntu 26.04 / USB-10T1S(enx001ec0d1c337, 192.168.10.10, PLCA 协调者) /
S32K312 板 (192.168.10.13, PLCA id=3, 软件 SPI ~3 MHz) / 总线约 2 m。

## 6. 修复前的两个关键 bug（已修复并验证）

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 104 字节帧只重组出 41 字节 | 非结束块 (EV=0) 的 EBO 无效，代码误用 ebo+1 | 非结束块整块拷贝 |
| `s2500 reg 0 0` 参数错位 / password 提示 | letter-shell CMD_FUNC 语义 + 默认用户名与命令重名 | 改用 CMD_MAIN；用户名改 root |

## 7. 性能（软件 SPI ~3 MHz，临时方案）

| 项目 | 数值 |
| --- | --- |
| bench tx 100×500B | 303 ms（330 fps，~1.3 Mbit/s） |
| bench tx 5×100B | 4 ms |

> 上限受软件 SPI 限制。硬件 LPSPI0 调通后预计可到 8–9 Mbit/s（参考 LAN8651 旧工程 8.86 Mbit/s）。
