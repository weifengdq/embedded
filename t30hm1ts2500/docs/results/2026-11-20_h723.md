### 3.1 TCP 窗口调优

下行最初只有 **7.44 Mbit/s**；把 SPI 从 12.5 MHz 提到 25 MHz **完全没变化**，说明瓶颈不在 SPI。
把 lwIP `TCP_WND` 从 2×MSS 提高：

| TCP_WND | 下行 Mbit/s |
| --- | --- |
| 2920（2×MSS，默认） | 7.44 |
| 5840（4×MSS） | 8.80 |
| **8760（6×MSS，本工程默认）** | **9.07** |
| 11680（8×MSS） | 9.07（无进一步收益） |

## 5. 两个 H7 特有现象

1. **SPI 必须置 CR1.CSTART**：H7 的新 SPI IP 只置 `SPE=1` 不出时钟；不置 `CR1.CSTART`
   会导致 RX DMA 不动、1 ms 超时后回退轮询，性能骤降。本工程 DMA 占比 100%、回退 0。
2. **LKST 不能单独作为判据**：上电/复位后 LKST 需 5–10 s 才 UP；bench 连续高速发送时
   LKST 会瞬时 DOWN（终端过量，`single_col` 上升），但 ping 0% 丢包、iperf 满速。
   **判据应用 ping + `s2500 counters`**（fcserr/overflow/underflow 不增长）。
